🔗 Vendit PMS 연동

Vendit 예약 시스템과 연동하여 예약 데이터를 자동으로 고객 DB에 동기화합니다.

연동 설정 가이드

  1. Vendit 로그인 → 설정 → API 관리 메뉴에서 API 키 발급
  2. 서버의 .env 파일에 VENDIT_API_KEY 입력
  3. 서버를 재시작한 후 위의 동기화 버튼을 클릭
  4. Vendit에 API 기능이 없을 경우, Vendit 고객센터에 API 연동 문의
